# Quick Start Guide

Welcome to the Operating Systems: Three Easy Pieces exercise templates!

## 🎯 Quick Start (5 minutes)

### 1. Clone and Build
```bash
git clone https://github.com/alektebel/3-easy-pieces-exercises.git
cd 3-easy-pieces-exercises
make
```

### 2. Pick Your First Exercise
We recommend starting with: **virtualization/cpu-intro-template.c**

```bash
# Open in your favorite editor
vim virtualization/cpu-intro-template.c
# or
code virtualization/cpu-intro-template.c
```

### 3. Read and Implement
1. Read the OBJECTIVE section at the top
2. Follow the GUIDELINES 
3. Fill in the TODO sections with your code
4. Compile: `make virtualization/cpu-intro-template`
5. Run: `./virtualization/cpu-intro-template`

### 4. Check Your Work
- Compare output with the EXPECTED OUTPUT in the solution section
- If stuck, enable the solution (change `#if 0` to `#if 1`)
- Read the EXPLANATION to understand the concepts

## 📚 Learning Path

### Beginner Track
1. `virtualization/cpu-intro-template.c` - Learn about processes
2. `virtualization/memory-api-template.c` - Learn about memory
3. `persistence/file-io-template.c` - Learn about files

### Intermediate Track  
4. `concurrency/threads-intro-template.c` - Learn about threading
5. `concurrency/locks-mutex-template.c` - Learn about synchronization

## 💡 Pro Tips

- **Don't peek at solutions too early!** The struggle helps you learn.
- **Compile often** to catch errors quickly
- **Experiment** by breaking things - see what happens!
- **Read the explanations** even if your code works
- **Use debugging tools** like `gdb` and `valgrind`
